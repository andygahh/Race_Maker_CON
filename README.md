# RaceMaker (Console Version)

## Welcome to RaceMaker

This is an application designed to randomize tracks for *Mario Kart World* on the Nintendo Switch 2.  
When creating a custom race in-game, the options for customization are limited.  
RaceMaker expands on that by letting you configure races and Grand Prix events in a bunch of new ways.

### Planned Options
- Intermission track toggle  
- Region-specific track filters  
- Cup-specific track filters  
- ...and more unforeseen features as development continues  

As of writing this README, RaceMaker is at **version 0.01** — a console-based build.  
The next major step will be upgrading to a **WPF GUI application**.  
I’ll keep this repo updated with each version and include notes on what’s changed.

Thanks for checking it out — this is my first major app development project. Cheers!
